# Project progress

Updated 2026-10-26. Full implementation is authorized and active. This file records the current workspace state; it is not a claim that the product is complete.

## Current product direction

- Web app first, with a chat-first Workspace interface. A desktop wrapper is optional later.
- The bundled Operating Systems and IoT enriched trees are active resources. Their interpretation notes remain visible, but no faculty approval gate is required.
- Uploads take effect when submitted. Explicit requests to delete a paper, question, material or template take effect immediately. There is no faculty confirmation step for those actions.
- Actual paper patterns and custom templates will be configured later. Their absence must not block building the application.
- The target machine has 8 GB VRAM. Judge and helper are separate sequential roles and may share one local model artifact; both roles and OCR must be measured on that hardware.
- PostgreSQL with pgvector is the primary database. SQLite is retained for isolated tests and single-user fallback only.

These are the latest user decisions. Earlier approval language in the original spec and chat transcript is historical where it conflicts with them; `project-handoff/decisions.md` now records the current direction.
